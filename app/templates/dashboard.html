Project Abstract

{{ branding.projectTitle }} is a privacy-first document protection system that detects Aadhaar information from uploaded images, masks sensitive regions, and returns integrity evidence for audit. The solution combines OCR-driven extraction with configurable masking policies, response hashing, API key enforcement, rate limiting, and operational visibility for secure deployments.

Objective: Prevent exposure of Aadhaar in shared image workflows.
Core Tech: Flask, OCR pipeline, hashing (SHA-256/HMAC), secure API design.
Security Controls: API key gate, rate limiting, raw Aadhaar redaction by default.
Evidence Layer: Input/output file hashes, job ID, UTC processing timestamp.
